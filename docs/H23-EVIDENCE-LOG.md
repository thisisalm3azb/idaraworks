- UK employer NI secondary threshold: the gov.uk fetch summarized '15% above £481/week' which conflicts with the £96/week (£5,000/yr) threshold introduced April 2025 — never hardcode UK thresholds; import from HMRC tables per tax year at pack build.

**Unresolved → explicit configuration:**
- Monthly-basic-to-hourly conversion divisor: neither Decree-Law 33/2021 nor Cabinet Resolution 1/2022 fixes how to derive the hourly basic rate from a monthly basic salary. Market practice splits between basic/30/8 (commonly attributed to MOHRE practice) and basic x 12/365/8. Make this an explicit org configuration (suggest default basic/30/8) rather than hard-coding.
- Rest-day pay base (Art 19(4)): the base day pay is 'the wage established for normal business days' while only the 50% uplift is explicitly on basic wage — whether the base component is full daily wage or daily basic is ambiguous. Expose as config (base = basic vs gross daily wage), premium always on basic.
- Who elects between the compensatory rest day and the 150% cash settlement for rest-day work (employer vs worker) is not specified in Art 19(4). Encode as an org policy setting driving the approval workflow.
- Whether shift workers excluded from the 50% night premium (Art 19(3)) still receive the ordinary 25% OT rate for overtime in the 22:00-04:00 window is not stated; universal practice assumes yes. Default the shift-worker fallback multiplier to 1.25 but keep it configurable.
