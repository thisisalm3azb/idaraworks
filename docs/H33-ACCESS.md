# H33 — Pilot Lab access and test users

Generated by `npx tsx tooling/pilot-lab/access-report.ts` from
`tooling/pilot-lab/companies.ts`. Every address below is produced by the
same function the launcher signs in with, so this list cannot drift from
the accounts that exist.

## How to sign in

You will never be given a password, because none was kept. Each account was
created with 24 random bytes as its password, which were discarded the moment
the account existed — never stored, printed or transmitted. Signing in mints a
**one-time** link through the Supabase Admin API, aimed at the app's own
`/auth/confirm` route, which consumes it exactly once:

```bash
npm run lab:open -- gulfbuild owner
```

The first argument is the company key, the second the persona key — both
from the tables below. Add `--no-browser` to print the link instead of
opening it. Run `npm run lab:open` with no arguments to list everything.

If a page 404s while the rest of the app works, clear the build cache first
(`rm -rf .next`) — a stale one makes whole modules look missing.

## Why this is safe

- **No password is recoverable.** Each account has one, generated as 24
  random bytes and thrown away unread, so there is nothing to guess, reuse or
  leak — and nothing to rotate. The one-time link dies on first use and
  expires in about an hour. A project admin could set a password from the
  Supabase dashboard; nothing in this repository can.
- **The addresses cannot receive mail.** `.invalid` is reserved by RFC 2606
  precisely so it can never resolve. Nothing sent to these accounts can
  reach a real inbox.
- **Test project only.** Every lab tool loads `.env.test.local` explicitly
  and refuses to run against anything that resolves to production. There is
  no override flag.
- **Minting a link needs the service-role key**, which lives only in
  `.env.test.local` on your machine and is not in the repository.
- **The people are fictional** — invented names, addresses, bank details and
  tax identifiers throughout. No real person's data is in the lab.

## Leaving the lab alone

Nothing here writes to the lab. `lab:open` mints a link and starts the app;
the app itself is the product, so anything you change while signed in is a
real change to that company's data — which is the point. To put a company
back the way it was, the whole lab has to be rebuilt; there is no undo.
